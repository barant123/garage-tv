One-time setup: search, trending and channels need a free YouTube API key.

  1. On a PC, open console.cloud.google.com, make a project, enable "YouTube Data API v3".
  2. Credentials → Create credentials → API key. Restrict it to website barant123.github.io.
  3. Paste the key in Settings here. Then bookmark the car link so the car never needs it typed.
