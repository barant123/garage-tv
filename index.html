YouTube

A free YouTube Data API key turns on search, trending, categories and followed channels. Make one at console.cloud.google.com (enable "YouTube Data API v3", then Credentials → API key, restricted to the website barant123.github.io).

Traffic: police and hazards

Without a relay the Traffic box shows Waze jams only. A free Cloudflare Worker relay (file tools/waze-relay.js in the repo, setup steps inside it) adds police, crashes, hazards and closures on a clean map. Paste the worker's address here.

Car link (no typing in the car)

This link carries every preference on this page: key, playlist, relay, tickers, teams, followed channels and location. Bookmark it in the car. If the car browser forgets its settings after an update, opening the bookmark restores everything.

Location

Weather and traffic follow the car: the page asks the browser for location (allow it once in the car). If that is refused it falls back to the connection's rough location.
